首次打开提示「身份不明」或「已损坏」解决流程

由于 Maple 是免费开源应用，暂未购买 Apple 付费公证证书，macOS 首次打开时可能会触发安全拦截。按以下任一方式即可解决：

方式一：按顺序点击通过（内置修复工具） ⬇️ 下载修复工具

1. 打开 DMG：若双击 .dmg 被拦截，请在「下载」中右键（或按住 Control）点击 .dmg → 选择「打开」；

2. 拖入安装：将左侧 Maple 拖入右侧 Applications 文件夹；

3. 一键修复：右键点击 DMG 底部的「首次打开修复」→ 选择「打开」，即可自动配置权限并启动 Maple！

方式二：终端一键免拦截安装（全程 0 弹窗 · 最省心）

打开系统自带的「终端 (Terminal)」，复制以下命令回车，自动下载安装并放行：

$ curl -fsSL https://liceal.github.io/maple/install.sh | bash
$ brew install liceal/tap/maple
方式三：已安装但提示「已损坏」？一行命令放行
$ xattr -cr /Applications/Maple.app
